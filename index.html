Exercise 4.1: Draw SVGs

A house and garden drawn by hand with every basic SVG shape: rect, circle, ellipse, line, polyline, polygon, path and text, plus the group element <g>.

Step 1 & 3: My SVG house and garden

The svg uses viewBox="0 0 600 400", so it keeps its shape and scales to the width of the page.

Step 2: The SVG coordinate system

The origin (0, 0) is the top-left corner. x grows to the right and y grows down, so the ground (y = 320) has a bigger y than the roof top (y = 90). Each red dot marks the coordinate written in the code for that shape. The screenshots show my finished picture, including the Step 3 customisations. Screenshot 3 marks the new items from Step 3.

ShapeAttributes that position itUsed for

Step 4: The group element <g>

Both windows sit inside one <g id="windows">. The fill, stroke and stroke-width are set once on the group and every child inherits them. Each window is its own inner group moved with transform="translate(x, y)", so the rect and lines inside can use simple coordinates starting at 0,0.

<g id="windows" class="windows" fill="#9fd3f0" stroke="#4f3f28" stroke-width="3">
  <g class="window" transform="translate(170, 205)">
    <rect x="0" y="0" width="45" height="40" />
    <line x1="22.5" y1="0" x2="22.5" y2="40" />
    <line x1="0" y1="20" x2="45" y2="20" />
  </g>
  <g class="window" transform="translate(305, 205)"> ... same shapes ... </g>
</g>
